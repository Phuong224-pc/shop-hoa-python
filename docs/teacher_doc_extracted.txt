1. GIỚI THIỆU ĐỀ TÀI
1.1. Mô tả bài toán
[Giới thiệu ngắn gọn đề tài (website bán hàng, hệ thống quản lý...); đối tượng người dùng; vấn đề thực tế mà ứng dụng giải quyết. Khoảng nửa trang.]
1.2. Mục tiêu và phạm vi
[Mục tiêu: xây dựng ứng dụng web hoàn chỉnh bằng Flask với các chức năng bắt buộc: đăng nhập/đăng ký, CRUD (thêm/sửa/xóa/hiển thị), tìm kiếm, phân trang; và các chức năng mở rộng của nhóm (thanh toán, gửi email, API...). Phạm vi: giới hạn nghiệp vụ, số lượng chức năng cam kết.]
1.3. Công nghệ sử dụng
[Liệt kê: Python 3.x, Flask, Flask-WTF, Flask-SQLAlchemy, Flask-Mail, Jinja2, Bootstrap, SQLite/MySQL, urllib/requests + JSON (nếu tích hợp API), Git/GitHub...]
1.4. Phân công công việc trong nhóm
[Bảng phân công: thành viên nào phụ trách chức năng nào (models, forms, routes, templates, kiểm thử, viết báo cáo) và mức độ đóng góp %. Đã có bảng thành viên ở trang bìa, tại đây ghi chi tiết theo chức năng.]
2. PHÂN TÍCH VÀ THIẾT KẾ HỆ THỐNG
2.1. Chức năng của hệ thống
[Liệt kê chức năng theo nhóm người dùng (khách, thành viên, quản trị). Vẽ sơ đồ chức năng hoặc use case (Hình 2.1). Đánh dấu rõ chức năng bắt buộc: đăng nhập/đăng ký, CRUD, tìm kiếm, phân trang; và chức năng mở rộng.]
2.2. Thiết kế cơ sở dữ liệu
[Sơ đồ quan hệ giữa các bảng/model (Hình 2.2). Mô tả các model SQLAlchemy theo Bảng 2.1: tên bảng, các cột, khóa chính/ngoại, quan hệ (one-to-many, many-to-many).]

3. XÂY DỰNG ỨNG DỤNG VỚI FLASK
[Chương này bám theo các nội dung đã thực hành (chương 1–7) và thể hiện phần mở rộng của nhóm. Chỉ trích các đoạn mã TIÊU BIỂU, không dán toàn bộ code.]
3.1. Môi trường và cấu trúc dự án
[Cách tạo virtual environment, cài đặt gói (pip install -r requirements.txt) — theo bài thực hành Installation. Cấu trúc thư mục dự án theo mô hình Large Application Structure: package app/, blueprints, app factory (create_app), file cấu hình config.py; kèm cây thư mục.]
3.2. Routes và xử lý nghiệp vụ
[Các route chính (@app.route / blueprint), phương thức GET/POST, xử lý đăng nhập/đăng ký (session hoặc Flask-Login), phân quyền. Theo bài thực hành Basic Application Structure.]
3.3. Templates với Jinja2
[Kế thừa template, truyền biến, vòng lặp/điều kiện trong Jinja2, tích hợp Bootstrap; phân trang khi hiển thị danh sách. Theo bài thực hành Templates.]
3.4. Web Forms với Flask-WTF
[Các lớp form (FlaskForm), validator, hiển thị lỗi, bảo vệ CSRF; form đăng ký/đăng nhập, form thêm/sửa dữ liệu, form tìm kiếm. Theo bài thực hành Web Forms.]
3.5. Cơ sở dữ liệu với Flask-SQLAlchemy
[Khai báo model, tạo CSDL, thao tác CRUD (query, add, commit, delete), migration (Flask-Migrate nếu dùng). Theo bài thực hành Databases.]
3.6. Gửi email với Flask-Mail
[Cấu hình SMTP, gửi email xác nhận đăng ký/đặt hàng/đặt lại mật khẩu. Theo bài thực hành Email. Nếu nhóm không dùng email, thay bằng chức năng tương đương và giải thích.]
3.7. Lập trình mạng và tích hợp API
[Bắt buộc thể hiện CLO3: dùng urllib/requests đọc dữ liệu JSON/XML từ API bên ngoài (thời tiết, tỷ giá, bản đồ, thanh toán...) hoặc tự xây dựng REST API trả về JSON cho ứng dụng; mô tả API key và cách gọi.]
3.8. Chức năng mở rộng của nhóm
[Điểm cộng sáng tạo: thanh toán trực tuyến, giỏ hàng, thống kê biểu đồ, upload ảnh, chatbot, triển khai Docker/hosting... Mô tả ngắn cách thực hiện.]
4. KẾT QUẢ VÀ KIỂM THỬ
4.1. Kết quả giao diện

4.2. Kiểm thử chức năng
